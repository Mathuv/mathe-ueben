# Mathe üben

## Deutsch

[Mathe üben öffnen](https://mathuv.github.io/mathe-ueben/)

Die Seite speichert die Punkte nur im Browser auf diesem Gerät.
Jeder Browser und jedes Gerät hat eigene Punkte.
Die Seite sendet keine Daten und braucht keine Anmeldung.

Auf dem iPhone oder iPad: Fügen Sie die Seite zum Home-Bildschirm hinzu.
Öffnen Sie die Seite immer dort, damit die Punkte bleiben.

Die Aufgaben folgen den Themen der 4. Klasse (Lehrplan 21).
Die Seite erstellt eigene Aufgaben und enthält keine Texte aus einem Schulbuch.

## English

[Open Mathe üben](https://mathuv.github.io/mathe-ueben/)

The page saves the points only in the browser on this device.
Each browser and each device has its own points.
The page sends no data and needs no login.

On an iPhone or iPad, add the page to the Home Screen.
Always open the page there to keep the points.

The problems follow the topics of class 4 (Lehrplan 21).
The page makes its own problems and contains no text from a textbook.
